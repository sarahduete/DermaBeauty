# 🌸 Derma Beauty

**Sistema de gestão e agendamento para clínica de estética**

O Derma Beauty é um projeto desenvolvido com o objetivo de criar uma plataforma para uma clínica de estética, permitindo apresentar tratamentos, realizar cadastros de clientes e organizar agendamentos.

🔗 **[Acessar o site](https://dermabeauty.onrender.com/)**

---

## 📖 Sobre o projeto

O Derma Beauty surgiu da ideia de desenvolver um sistema voltado para clínicas de estética, reunindo em um único ambiente informações sobre tratamentos e funcionalidades para facilitar a organização dos atendimentos.

A proposta foi criar uma plataforma que tivesse tanto uma parte institucional, para apresentar a clínica e seus serviços, quanto uma área destinada aos clientes e outra para o gerenciamento administrativo.

## 💻 Como foi desenvolvido

O desenvolvimento começou com o planejamento da estrutura do sistema e a definição das funcionalidades que seriam necessárias.

Primeiramente, trabalhei na identidade visual, buscando uma aparência elegante, delicada e minimalista, utilizando tons de rosa, branco e cores neutras para transmitir a proposta da marca.

Depois, comecei a estruturar as páginas utilizando HTML e CSS, organizando os elementos e criando uma navegação simples e intuitiva.

Com a parte visual encaminhada, iniciei o desenvolvimento das funcionalidades utilizando PHP. Nessa etapa, trabalhei com formulários, cadastro e login de clientes, conexão com o banco de dados e gerenciamento das informações.

Também implementei a funcionalidade de agendamento, permitindo que o cliente selecione um tratamento, escolha uma data e consulte os horários disponíveis.

Para armazenar as informações, utilizei SQLite, integrando o banco de dados às funcionalidades do sistema.

Durante o processo, precisei lidar com diferentes desafios, principalmente na integração entre as páginas, o banco de dados e a disponibilidade dos horários. Esses ajustes fizeram parte do aprendizado e contribuíram para a evolução do projeto.

## ⚙️ Funcionalidades

### Área do cliente
- Cadastro de clientes.
- Login e autenticação.
- Consulta de tratamentos.
- Agendamento de atendimentos.
- Consulta dos próprios agendamentos.

### Painel administrativo
- Gerenciamento de tratamentos.
- Visualização e gerenciamento de agendamentos.
- Organização dos atendimentos.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Utilização |
|---|---|
| HTML | Estrutura das páginas |
| CSS | Estilização e identidade visual |
| PHP | Funcionalidades e processamento |
| SQLite | Armazenamento dos dados

## 📚 Aprendizados

O desenvolvimento do Derma Beauty foi uma oportunidade de aprofundar meus conhecimentos em PHP, integração com banco de dados e construção de sistemas web.

Durante o projeto, pude compreender melhor como diferentes partes de uma aplicação se conectam, desde a interface apresentada ao usuário até o processamento e armazenamento das informações.

Também aprendi a identificar erros, testar funcionalidades e realizar ajustes para melhorar o funcionamento do sistema.
